# Katipunan

**Katipunan** is a historically based click-and-drag game inspired by the Philippine Revolution. The game features three major battles and allows players to experience simplified versions of these historical events through interactive gameplay.

## About the Game

Players control revolutionary characters using click-and-drag mechanics to complete objectives, fight enemies, protect civilians, and maintain their forces' morale.

The game features three major battles:

* Battle of San Juan del Monte
* Battle of Imus
* Battle of Zapote Bridge

Each battle contains **three stages**, with difficulty increasing as the player progresses.

## Gameplay

Players can control different character roles:

* **Melee Fighter** – attacks enemies at close range.
* **Ranged Fighter** – attacks enemies from a distance.
* **Healer** – restores the health of nearby allies.

The main gameplay objective is to maintain **morale**. Morale can increase through successful actions and protecting civilians, while losing characters or failing objectives can decrease it.

## Development Tools

* **Godot Engine** – Game development
* **GDScript** – Game programming
* **FL Studio** – Music production
* **Autodesk SketchBook** – Concept art

## How to Run

1. Install **Godot Engine**.
2. Clone or download this repository.
3. Open `project.godot` in Godot.
4. Run the project.
